# THE.TRAIL Clients 0.1.13

Добавлена вкладка «Учёт». В ней доступны сводка за месяц, операции и движение клиентов. В карточке клиента можно настроить несколько услуг, записать оплату и проведённое персональное занятие. Напоминания о неоплаченных периодах появляются в отдельном блоке ToDo.

Поступления учитываются по фактической дате и валюте. Один платёж можно распределить по услугам, клиентам и месяцам. Расходы и стоимость проведённых занятий считаются отдельно. Остаток аванса виден в карточке клиента. Данные учёта входят в локальную резервную копию.

Обычное обновление интерфейса поверх APK 0.1.10. Существующие карточки и задачи сохраняются. Исторические платежи из Google Sheets не загружаются автоматически.
