# THE.TRAIL Clients 0.1.10

В карточке клиента появилась кнопка «Разрешить микрофон». Она вызывает системное окно Android; после согласия начинается запись. Если Android уже запрещает повторный запрос, кнопка открывает настройки именно THE.TRAIL Clients. После возврата доступ проверяется снова, текстовый ввод остаётся доступным.

Исправлено отсутствующее MODIFY_AUDIO_SETTINGS: WebView требует его вместе с RECORD_AUDIO. Раньше это могло приводить к отказу записи даже при разрешённом микрофоне.

Нужен новый APK 0.1.10: установить поверх текущего приложения без удаления. База, Telegram и настройки подключения сохраняются. Обычного обновления интерфейса недостаточно для изменения системных разрешений.
