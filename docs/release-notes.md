# THE.TRAIL Clients 0.1.14

Список клиентов показывает имена по алфавиту. Поиск работает по кириллице и латинице. Быстрые кнопки «Онлайн», «Очно» и «Зал» применяются сразу. Остальные параметры находятся в разделе «Фильтр».

В «Учёте» появился импорт личного файла бухгалтерии. Он добавляет имена на кириллице, историю, месячные итоги и проверенные привязки Telegram в пустые карточки. Ранее внесённые операции и существующие привязки сохраняются. В карточке видны последняя оплата и строки бухгалтерии. Повторяющиеся строки и суммы, требующие сверки, отмечены отдельно.

Обновление интерфейса устанавливается поверх APK 0.1.10. Личный файл передаётся отдельно и загружается через «Учёт → Импорт учёта».
