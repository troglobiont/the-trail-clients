# THE.TRAIL Clients 0.1.82

- Логотип открывает просмотр ролей «Суперадмин», «Тренер», «Бухгалтер» и «Спортсмен» в текущем аккаунте.
- Тренер видит своё расписание, сокращённые контакты и приём оплаты по доступным услугам. Бухгалтер работает с полной карточкой клиента и учётом.
- В режиме спортсмена доступны свой профиль, тренировки, операции и задачи, которыми поделился тренер. Вопрос из профиля становится задачей тренера.
- В режиме Шелкового Сергея в «Админ → Интеграции» доступна ссылка на Garmin Connect. Индивидуальный вход и подключение Garmin запланированы на следующую итерацию.
