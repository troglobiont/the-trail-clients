# THE.TRAIL Clients 0.1.9

Голосовой ввод начинается с основной кнопки при пустом поле: «Надиктовать запись». Вводить символы для активации больше не нужно. Та же кнопка останавливает запись, показывает распознавание, а после появления текста передаёт его агенту. Сохранённую аудиозапись можно повторно распознать этой же кнопкой.

Если агент ещё выключен, действие явно называется «Включить агента и надиктовать» или «Включить агента и обработать»; подключение проверяется и AI включается по этому нажатию. При отказе доступа к микрофону показывается понятное сообщение.

Короткий текст без выделенных действий получает явное пояснение, вместо молчаливого сохранения в историю. Существующая база и Telegram-привязки сохраняются, обновление совместимо с APK 0.1.6.
