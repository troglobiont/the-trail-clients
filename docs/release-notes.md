# THE.TRAIL Clients 0.1.19

В разделе «Настройки → Оформление» доступны четыре палитры: графит, кобальт, терракота и слива. Каждая поддерживает светлый и тёмный режимы. По умолчанию включён светлый графит.

Выбор применяется сразу и сохраняется на устройстве. Установите выпуск кнопкой «Обновить сейчас» в настройках приложения.
