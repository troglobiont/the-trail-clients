# THE.TRAIL Clients 0.1.77

- «Тренировочные данные» оформлены компактными вложенными блоками по образцу тарифов. Каждая запись открывается отдельно, со стрелкой возврата к прежнему списку.
- Короткие названия и значения вместо длинных пояснений. Источники, статусы и основания сохранены в сворачиваемых «Подробностях» записи.
- В сводке спортсмена: цель, LT1 слева и LT2 справа, зоны, RHR. Показатели открывают соответствующие записи.
- Особенности перенесены в «Ограничения» внутри сводки спортсмена. Добавление, исправление и снятие актуальности работают с прежними записями.
- Тип цели выбирается в компактном раскрывающемся списке внутри формы, с поддержкой клавиатуры.
- Изменения касаются представления данных; сохранённые показатели и зоны не пересчитываются.
