# THE.TRAIL Clients 0.1.42

- Во вкладке «Учёт → К получению» видны клиенты с неоплаченными персональными занятиями. Можно раскрыть даты и принять частичную или полную оплату.
- Историю в карточке можно отфильтровать по виду записи и тарифу, например показать только оплаты группы Белграда или персональных.
