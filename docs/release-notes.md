# THE.TRAIL Clients 0.1.51

- В истории клиента поступления помечены зелёным «+», а стоимость проведённого занятия показана со знаком «−». Если полная оплата привязана к занятию в тот же день, отображается «Проведено и оплачено».
- У занятия, поступления и совместной записи одинаковая карточка подробностей. Команды редактирования находятся в блоке «Исправить запись».
