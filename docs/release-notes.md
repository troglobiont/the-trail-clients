# THE.TRAIL Clients 0.1.33

- Контакты можно заполнить при создании клиента. Форма проверяет основной телефон, email, город, профессию, день и месяц рождения.
- При вводе любого телефона подставляется «+». Дополнительный телефон, Telegram, Instagram и год рождения можно оставить пустыми.
- Варианты «Beograd», «Belgrade» и «Београд» отображаются как «Белград».
