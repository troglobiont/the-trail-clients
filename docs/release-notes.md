# THE.TRAIL Clients 0.1.112

- У спортсмена пять вкладок: «Сегодня», «Календарь», «Тренер», «Старты» и «Профиль».
- Календарь показывает назначения, групповые и персональные встречи. «Сегодня» открывает выбранный день в календаре.
- В «Тренере» видны отправленные вопросы и ответы. Оплаты доступны из профиля, тренировочные данные — через «Прогресс».
