THE.TRAIL Clients 0.1.6 — исправление нативного обновления Android.

Исправлен мгновенный отказ до скачивания: ID GitHub-файла приходит из JSON-моста как Integer, а PluginCall.getLong принимал только Long. Теперь ID проверяется и читается из всех корректных целочисленных Number. Проверки HTTPS-адресов и SHA-256 сохранены.

Для перехода с предыдущей оболочки нужен подписанный APK 0.1.6 (versionCode 5), установленный поверх приложения. Удалять приложение не нужно. Начальная база в личном APK применяется один раз; существующие карточки, задачи, настройки и черновики сохраняются.

Ошибки обновления показывают этап и различают неверный ID, ограничения GitHub, нехватку места, TLS, тайм-аут и ошибку сохранения. Нажатие «Обновить сейчас» во время фоновой проверки запускает установку после её завершения.

Включены подключение Telegram по коду с Mac и явная привязка контакта. Само подключение сообщений не отправляет. Публичные пакеты не содержат личных данных или ключей.
