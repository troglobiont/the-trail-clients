# THE.TRAIL Clients 0.1.74

- Вместо длинного статуса в шапке — облачко с отметкой состояния. Нажатие запускает синхронизацию; при необходимости входа или выборе версий открываются соответствующие настройки.
- Галочка означает успешную синхронизацию, стрелка — ожидающие изменения, вращающаяся стрелка — проверку; отсутствие связи и ошибки имеют отдельные значки.
- В настройках видна дата последней успешной проверки, включая проверку без изменений.
- Настройки снова доступны отдельным колесом со спицами справа, с отступом от края. Логотип слева стал обычным логотипом.
