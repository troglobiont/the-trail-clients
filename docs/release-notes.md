# THE.TRAIL Clients 0.1.7

Выбор Telegram-получателя: крупные строки с переключателем, явная подсветка выбранного контакта. «Сохранить» доступно после выбора. Закрытие клавиатуры с неизменённым запросом больше не сбрасывает результаты. Устаревшие ответы поиска игнорируются, Enter запускает поиск.

Поиск по имени в контактах и точному @username. Личный Mac-сервис поддерживает подтверждённые тренером соответствия ФИО и имени в Telegram; они хранятся приватно на Mac. Привязка не отправляет сообщений.

Обновление интерфейса поверх APK 0.1.6, база и настройки сохраняются.
