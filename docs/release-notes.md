# THE.TRAIL Clients 0.1.81

- Если сервис Telegram недоступен, карточка показывает статус попытки и позволяет скопировать заготовку и открыть чат. Повтор запроса использует прежний идентификатор. Закрытие попытки не записывает контакт как отправленный.
- В карточке «Спортсмен» собраны RHR, LT1, LT2, рабочие зоны ЧСС, нагрузка, восстановление, ограничения и свёрнутый список целей.
- В «Нагрузке» можно записать выполненные тренировки и дни отдыха. ATL, CTL и TSB рассчитываются в единицах session‑RPE. Для велотренировки доступен отдельный TSS по мощности.
- В «Восстановлении» хранятся наблюдения и самоотчёт. Индекс рассчитывается по отклонениям от личной нормы, когда набрана сопоставимая история.
