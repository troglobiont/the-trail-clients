# THE.TRAIL Clients 0.1.17

В карточке клиента можно сохранить занятие и оплату одним действием. Для уже проведённого занятия подставляется сумма к оплате. Остаток аванса показывает, на сколько занятий его хватит по текущему тарифу.

Быстрый учёт доступен в списке клиентов и в разделе «Учёт». После сохранения из раздела «Учёт» снова открывается поиск клиентов.

Тарифы и история раскрываются в карточке. Раздел «Сообщения в Telegram» свёрнут по умолчанию. У кнопки «+ Добавить» рядом с особенностями появился отдельный контур.

Установите обновление через «Настройки → Данные и обновления».
