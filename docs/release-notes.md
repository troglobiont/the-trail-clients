# THE.TRAIL Clients 0.1.25

- Клубные старты 2027, участники по мероприятию и пять типов целей.
- Настройки открываются через шестерёнку. Голос и текст доступны из «Ассистента» в нижнем меню.
- Выполненная задача остаётся в открытой карточке до выхода, далее доступна в истории.
- Быстрая запись оплат и занятий, сводка по источникам поступлений, отдельные авансы и задолженности.
- Клиентов можно упорядочить по давности контакта. Напоминания об оплате отмечены в ToDo.
- Новый поиск по телефону в Telegram требует обновлённого сервиса на Mac.
