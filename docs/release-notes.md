# THE.TRAIL Clients 0.1.47

- В быстрой оплате для тарифов «Зал» и «Улица» видны обе галочки, «Занятие проведено» и «Оплата получена». Для сохранения нужно выбрать хотя бы одну.
- Сумма поступления появляется после отметки об оплате. Если отмечено только проведённое занятие, его стоимость учитывается в остатке аванса или долге.
