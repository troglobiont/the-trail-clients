# THE.TRAIL Clients 0.1.107

- «Оплаты → Открытые» объединяют незакрытые месячные тарифы и долги за проведённые персональные занятия.
- В сводке раскрытые разделы выделены, а расходы на рекламу видны за выбранный месяц.
- Сверенные с календарём отчёты о проведении групповых включаются в начисления команды.
