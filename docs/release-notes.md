# THE.TRAIL Clients 0.1.11

В действиях по клиенту появилась кнопка «Редактировать»: можно изменить текст и дату задачи. Нажатие на текст больше не завершает задачу — для выполнения есть отдельная галочка «Выполнено». Переписка, история и состояние задачи сохраняются при редактировании; выполненную задачу тоже можно исправить или вернуть в работу.

Во время диктовки кнопка «Остановить и распознать» становится красной со значком остановки. При распознавании и обработке кнопка синяя; после завершения возвращается обычный цвет.

Доступно обычное обновление интерфейса поверх APK 0.1.10. База и подключения сохраняются.
