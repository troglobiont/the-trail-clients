THE.TRAIL Clients 0.1.2 — первая установочная Android-версия.

Локальная база клиентов, ToDo, цели, особенности, история, импорт и экспорт. Вся плитка клиента открывает его карточку. Автопрокрутка к вводу цели. Сохранение черновиков и повторов обработки без дублей.

Обновления интерфейса: Настройки → Данные и обновления → Обновить сейчас. В закрытом GitHub-канале один раз нужен ключ чтения этого репозитория. Личная база не входит в APK или архив обновления.

После установки импортируйте отдельно переданный файл базы. Агент, голосовой разбор и Telegram подключаются к личному сервису; без сервиса доступны локальные записи, задачи и цели.
