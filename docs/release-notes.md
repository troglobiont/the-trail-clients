THE.TRAIL Clients 0.1.3 — автоматическая начальная база в личном установщике.

Личный APK может содержать начальную базу: при запуске она сохраняется на устройстве автоматически. Существующие правки, выполненные задачи и черновики сохраняются; повторный запуск не применяет начальную базу заново.

Публичные исходники, CI и архивы обновления не содержат клиентских данных. Личный установщик с базой передаётся отдельно. Для добавления начальной базы нужен APK 0.1.3; обновление только интерфейса на старой оболочке не добавляет личные данные.

Публичные обновления работают без ключа GitHub; подсказка в настройках исправлена.
