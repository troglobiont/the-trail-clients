# THE.TRAIL Clients 0.1.79

- В «Спортсмене» все неудалённые цели показаны отдельным списком, без скрывающей ссылки «Другие цели».
- Каждая цель занимает собственную кликабельную строку с разделителем и стрелкой. Длинное название переносится целиком; нажатие открывает соответствующую цель.
- Изменение касается отображения: существующие тексты, статусы, привязки стартов и порядок основной цели сохранены.
