# THE.TRAIL Clients 0.1.26

- Ассистент находит склонённые фамилии и предлагает варианты, когда расшифровка разделила фамилию или исказила её на одну букву.
- По неточному совпадению клиент выбирается вручную. Расшифровку можно отредактировать.
- Фраза «нужно оплатить» предлагает задачу. Сообщение «оплатила» предлагает внести полученную оплату.
