# THE.TRAIL Clients 0.1.16

В настройках появился раздел «Синхронизация». При первом подключении приложение объединяет базу на телефоне с данными личного проекта The.Trail Clients. Новые карточки, задачи, занятия и оплаты сохраняются локально и отправляются в облако при наличии связи. При конфликте можно выбрать версию записи.

Для защищённого хранения сеанса синхронизации установите подписанный APK 0.1.16 поверх существующего приложения. Карточки, задачи, учёт и подключения сохраняются.
