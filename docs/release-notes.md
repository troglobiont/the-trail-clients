# THE.TRAIL Clients 0.1.8

Добавлено подключение агента через Codex на личном Mac со входом ChatGPT. Расходуются доступные лимиты и кредиты Codex; OpenAI API остаётся отдельным явно выбираемым режимом. Автоматического перехода на платный API нет.

Голос можно расшифровывать локально через Whisper на Mac. В настройках есть «Проверить агента и голос». Во время расшифровки и разбора показывается ход обработки; сохранённую запись можно повторить при ошибке.

Обновление интерфейса поверх APK 0.1.6. Клиентская база, Telegram-привязки и ключи сохраняются. Для обработки Mac и его подключение должны работать.
