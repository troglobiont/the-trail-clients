# THE.TRAIL Clients 0.1.66

- В ToDo → ДР по умолчанию открываются «7 дней». В «Прошли» показываются дни рождения за последние семь дней без отметки о поздравлении.
- Вкладка «Оплата» показывает долги и предстоящие платежи на 7 или 30 дней.
- В расписании можно изменить дату, время и место тренировки или отменить её в Google Календаре. Под кнопкой «Обновить» находится свёрнутый список прошедших тренировок за текущий месяц.
