# THE.TRAIL Clients 0.1.12

Усилены тексты задач и важных особенностей. Вспомогательные кнопки стали легче, свёрнутые разделы — компактнее, заголовки и подписи — спокойнее. В ToDo главный акцент на действии, в списке клиентов — на имени. Основная кнопка диктовки и заметные состояния записи/распознавания сохранены.

После привязки Telegram видны получатель, «Изменить получателя» и «Отвязать переписку». Отвязку можно сразу отменить кнопкой «Вернуть». Временная недоступность сервиса не скрывает сохранённую привязку. Для непривязанного клиента показано только подключение переписки; заготовки появляются после привязки.

Обычное обновление интерфейса поверх APK 0.1.10. Клиентская база, задачи и подключения сохраняются.
