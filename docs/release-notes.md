# THE.TRAIL Clients 0.1.22

В списке клиентов по умолчанию видны активные. Разовые клиенты, клиенты на паузе и архив открываются отдельно. В разделе «На паузе» есть фильтры «С ориентиром» и «Без срока».

В учёте добавлены единый список пакетов и фильтры по пакету, валюте тарифа и валюте поступления.

Для приложения с APK 0.1.20 обновление доступно в разделе «Настройки → Данные и обновления».
