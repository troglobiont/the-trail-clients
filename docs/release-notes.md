# THE.TRAIL Clients 0.1.15

Проверка и загрузка обновлений используют прямые ссылки на файлы выпуска GitHub. Для этого маршрута ключ GitHub не требуется. Архив проверяется по SHA‑256 перед применением.

Если установленная версия сообщает об исчерпании лимита GitHub, скачайте подписанный APK 0.1.15 и установите его поверх приложения. Карточки, задачи, учёт и подключения сохраняются. В выпуск включены список клиентов и импорт учёта из 0.1.14.
