# THE.TRAIL Clients 0.1.36

- В карточке клиента видны статус оплаты по каждому тарифу, срок, остаток и задолженность за предыдущие месяцы. Оплата закрывает месяц, выбранный при записи.
- Быстрый фильтр «Оплаты» в списке клиентов переключается между оплаченными, ожидающими оплаты и просроченными.
- У месячного тарифа можно указать месяц начала начислений. Просрочка начинается после трёх календарных дней с даты платежа.
