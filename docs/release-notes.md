# THE.TRAIL Clients 0.1.50

- В расписании видны полные имена из карточек клиентов. При однозначном совпадении название и связь с клиентом обновляются в Google Календаре.
- Из карточки тренировки можно записать занятие, поступление новых денег или оба события. Для занятия за счёт аванса видно сумму списания и остаток.
- В истории персональных тренировок отдельная оплата показывает, сколько покрывает долг и сколько уходит в аванс.
