# THE.TRAIL Clients 0.1.71

- Новый раздел «Партнёры»: условия для участников, контакты, источники, заметки и задачи. Первые четыре подготовленные карточки доступны после синхронизации личной базы.
- Задачи партнёров появляются в ToDo и поддерживают фильтры сроков, завершение и возврат в работу.
- Неизвестные скидки и цены остаются неуказанными. Даты и источники подтверждения видны у условий; контакты Recovery Point из справочника требуют проверки.
- Ассистент перенесён в небольшую кнопку микрофона в шапке ToDo. В нижней навигации доступны ToDo, Клиенты, Партнёры, Старты, Учёт.
- Партнёры и их задачи синхронизируются отдельно от клиентов; старые версии получают совместимый ответ облака.
