# THE.TRAIL Clients 0.1.23

- «Клиенты»: отдельные свёрнутые категории, постоянный формат в быстрых фильтрах, классификация в редакторе карточки.
- Карточка: компактные особенности, открытые задачи сверху, восстановление из истории, контактные и тренировочные данные в сворачиваемых блоках.
- ToDo: единый список задач и напоминаний, переход к конкретной задаче. Цели можно связать со стартом и увидеть участников в разделе «Старты».
- Учёт: сводка поступлений из приложения и бухгалтерии, с исключением точных совпадений. Строки на сверке, начисления и занятия отделены от поступлений.
- Telegram: открытие привязанной переписки по ID в новом APK, отдельная отметка открытия и настраиваемое напоминание о переписке. В прежнем APK для контактов с username доступна ссылка t.me.
- Настройки: обновления наверху, редкие настройки свёрнуты.
