# THE.TRAIL Clients

Android-приложение тренера: клиентская база, ToDo, цели, важные особенности и история. Нативная оболочка Capacitor с включённым офлайн-интерфейсом. Это устанавливаемый APK; приложение не загружает внешний сайт для запуска.

## Установка

Подписанный APK размещается в [Releases](https://github.com/troglobiont/the-trail-clients/releases). Репозиторий закрытый: нужно войти в GitHub под аккаунтом с доступом. Файл `*-unsigned.apk` из CI не является готовым установщиком; использовать `THE-TRAIL-Clients-Android.apk` после локальной подписи.

Установить APK на Android. Первое открытие: «Настройки → Импортировать базу», выбрать отдельно переданный JSON. Клиентские имена, цели, сведения о здоровье и заметки не встроены в APK, исходники или архивы обновлений.

Application ID: `io.github.troglobiont.trailclients`. Он отличается от других приложений, в том числе оператора 38. Для последующего нативного обновления использовать тот же ключ подписи и повышать versionCode. APK ставится поверх старой версии, без удаления приложения.

## Что работает локально

- ToDo с фильтрами «Все», «Мои действия», «Нужен ответ».
- Кликабельные плитки клиентов, поиск и совместные фильтры; возврат к прежней выборке.
- Создание клиента и правка классификации; обычный и временный форматы отдельно.
- Независимые задачи, ручная отметка исходящего сообщения, сроки проверки, закрытие и возврат в работу.
- Отложенные темы с переносом в ToDo на дату.
- Цели: редактирование, обратимое удаление и восстановление.
- Актуальные и прежние особенности; регулярные правила рядом с системными данными.
- Записи и черновики, импорт/экспорт JSON.

Без сервиса обычная запись сохраняется в историю, пометки «Задача» и «Цель» сохраняют соответствующую сущность напрямую. В этом режиме длинный свободный текст не выдаётся за автоматический AI-разбор. Голос и реальная отправка в Telegram требуют настроенного личного сервиса.

## Хранение

Android: атомарный файл в закрытом каталоге приложения. Запись проверяется перед заменой; при ошибке записи состояние не объявляется сохранённым. Обновление интерфейса не удаляет этот файл. Автоматический Android backup отключён; резервная копия создаётся явно через системное меню экспорта.

Ключи подключений шифруются Android Keystore и не входят в резервную копию. Экспорт включает клиентские сведения и предназначен для личного хранения. Удаление приложения удаляет локальные данные, поэтому сохраняйте отдельную резервную копию.

Импорт по умолчанию добавляет отсутствующие записи и сохраняет существующие правки. Полное восстановление из копии — отдельный явно выбранный режим с предложением сначала экспортировать текущую базу.

Браузерный запуск используется для разработки; он имеет отдельное localStorage и не синхронизируется с Android. Общий сервер клиентской базы и автоматическая синхронизация между устройствами в 0.1.1 не включены.

## Обновления как в операторе 38

«Настройки → Данные и обновления → Обновить сейчас». Интерфейс загружается ZIP-пакетом через CapacitorUpdater. Перед скачиванием и переключением сохраняются база и черновики. Проверяются приложение, версия, нативная совместимость, адрес и SHA-256. После успешного открытия приложение подтверждает запуск; без подтверждения плагин возвращает предыдущий рабочий пакет.

Изменения интерфейса не требуют переустановки APK. Новые нативные плагины, системные разрешения или несовместимая оболочка требуют нового подписанного APK. Никакой подписки Capgo, его статистики и автоматической установки обновлений нет.

Канал закрытый. Один раз в приложении сохранить fine-grained GitHub token, ограниченный **этим репозиторием**, с `Contents: Read`. Он хранится зашифрованным на устройстве. Метаданные читаются через GitHub API; архив скачивается по временной ссылке GitHub, без передачи токена на сторонний хост. Инструкция выдачи доступа — [docs/updates.md](docs/updates.md).

## Агент, голос и Telegram

В `server/` находится необязательный личный сервис. Поддерживает OpenAI Responses со структурированным результатом, расшифровку аудио и отправку трёх заготовок через авторизованный личный Telegram-аккаунт. Без развёрнутого сервиса и собственных доступов эти подключения не активны.

Сервис не меняет TrainingPeaks и не отправляет сообщения по результатам AI-разбора. Отправку вызывает только нажатие конкретной заготовки. Успех Telegram записывается лишь после подтверждения; повтор одного запроса использует тот же идентификатор. [Настройка сервиса](docs/service.md).

## Разработка и выпуск

Node 24, pnpm 11.25.0, Java 21, Android SDK 36. Зависимости закреплены lock-файлами.

```sh
pnpm install --frozen-lockfile
pnpm --dir mobile install --frozen-lockfile
pnpm test
python3 -m unittest discover -s server/tests -v
pnpm build
pnpm check
pnpm package:update
cd mobile
pnpm exec cap sync android
cd android
bash gradlew --no-daemon assembleRelease
```

GitHub Actions собирает release APK без подписи и прикладывает `apksigner.jar` для локальной подписи. Закрытый ключ не передаётся CI. Механизм выпуска: [docs/updates.md](docs/updates.md).

Проверка на физическом Android-устройстве нужна отдельно от успешной компиляции. В частности: клавиатура, разрешение микрофона, системное меню экспорта, автопрокрутка к записи и полный цикл обновления с сохранением базы.
